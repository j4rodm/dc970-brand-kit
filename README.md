# dc970-brand-kit

Storage and coordination of the aesthetic decisions for DC970 media.

---

## What is this?

This repo is the single source of truth for DC970's visual identity — colors, typography, and usage rules for anything created under the DC970 name.

It exists so that slides, social posts, websites, print materials, and any other DC970 output look and feel consistent, regardless of who made them or what tool they used.

## How to use

The primary file is [`brand-kit-dc970.md`](brand-kit-dc970.md). Open it when you're:

- **Starting a new design** — reference the color palette and font stack before picking anything
- **Building or updating the site** — variable names and hex values match what's in `dc970-com`
- **Making slides or print materials** — use the type scale and color role guidance
- **Checking accessibility** — the WCAG contrast table lists safe and forbidden pairings

### Quick start

1. Open `brand-kit-dc970.md`
2. Go to **Quick Reference** at the bottom for copy/paste hex values and font names
3. For specific usage rules (when to use yellow vs. white, which combos to avoid), read the **Colors** and **WCAG** sections

### Fonts

Both fonts are free on Google Fonts:

- [Sora](https://fonts.google.com/specimen/Sora) — headings and display text
- [Space Grotesk](https://fonts.google.com/specimen/Space+Grotesk) — body text

For code/mono, use **Lucida Console** (system font, no import needed).
